01 · Variables

Variables

Wat is het?

Een variabele is een soort opslagplaats waarin je informatie kunt bewaren. Je geeft deze opslagplaats een naam, zodat je de informatie later kunt gebruiken.

Hoe hebben wij dit gebruikt?

Bij onze rekenmachine gebruikten we variabelen om de getallen die de gebruiker invoert op te slaan.

getal_1 = 5
getal_2 = 10

Hierdoor wordt getal_1 opgeslagen als 5 en getal_2 als 10.

02 · Data types

Data types

Data types geven aan wat voor soort waarde een variabele is. Wij hebben het gehad over: integer, float, string en list.

Integer

Een integer is een heel getal, zonder decimalen.

getal_1 = 10

Float

Een float is een getal met decimalen.

getal_2 = 10.5

String

Een string is tekst. De tekst staat altijd tussen enkele of dubbele aanhalingstekens.

naam = "jathan"

List

Een list is een lijst waarin je meerdere waarden kunt opslaan.

getallen = [0, 3, 5, 1, 7]
Bij onze programma's waren integers en floats vooral handig voor de rekenmachine en strings voor teksten en invoer.
03 · Operators

Operators

Operators zijn tekens waarmee je kunt rekenen of dingen kunt vergelijken.

+  optellen
-  aftrekken
*  vermenigvuldigen
/  delen

Bij onze rekenmachine hebben we operators veel gebruikt.

04 · Conditional statements

If en Else

Met if en else kan de computer een beslissing maken.

Voorbeeld bij ons gokspel

if gok == geheim_getal:
    print("goed geraden")
else:
    print("fout")
05 · Loops

While en For

Een loop zorgt ervoor dat een stukje code meerdere keren wordt uitgevoerd.

While

Een while-loop blijft doorgaan zolang een bepaalde voorwaarde waar is.

while gok != geheim_getal:
    gok = int(input("raad het getal: "))

Dit is handig voor ons raadspel, omdat je meestal vaker dan één keer moet raden om het getal te vinden.

For

Een for-loop gebruik je wanneer je iets een bepaald aantal keer wilt uitvoeren of door een lijst wilt gaan.

for getal in (1, 2, 3, 4, 5):
    print(getal)
06 · Comments

Comments

Comments zijn opmerkingen in je code die de computer niet uitvoert. Je gebruikt ze om uit te leggen wat er gebeurt.

# dit vraagt de gebruiker om een getal
07 · Input

Input

Met input kan de gebruiker iets invoeren.

naam = input("wat is je naam? ")

Bij onze rekenmachine gebruiken we input ook om de getallen van de gebruiker te weten.

Voorbeeld rekenmachine

getal_1 = input("geef het eerste getal: ")
08 · Print

Print

Met print laat je iets zien op het scherm.

print("welkom bij de rekenmachine")

Bij onze programma's gebruikten we dit om bijvoorbeeld het antwoord van de berekening of de uitslag van het spel te laten zien.

09 · Importing modules

Modules · Random

Een module bevat code die je kunt gebruiken in je eigen programma. Met import gebruik je de module.

Voor ons getallenspel gebruikten we de random-module om een willekeurig getal te kiezen.

Voorbeeld random-module

import random

geheim_getal = random.randint(1, 100)

Door deze module kiest Python een willekeurig getal tussen 1 en 100.

10 · Indentation

Indentation

Een indentation betekent dat regels code inspringen. In Python is dit heel belangrijk, omdat Python hiermee ziet welke code bij elkaar hoort.

if getal > 10:
    print("het getal is groter dan 10")

Je ziet hier dat er een tab of spaties staan vóór de print. Dat is de indentation.

Indentation is heel belangrijk bij Python. Als je die verkeerd gebruikt, kan de code niet werken.
11 · Git

Git

Git is een programma waarmee je de veranderingen in je code kunt bijhouden.

Je kunt het zien als een soort geschiedenis van je project. In Git houd je de verschillende versies van je code bij.

12 · GitHub

GitHub

GitHub is een online platform waar je Git-projecten kunt opslaan en delen.

Je kunt bijvoorbeeld een Python-code op GitHub zetten zodat je:

  • je code kunt bewaren;
  • vanaf een andere computer bij je code kunt komen;
  • samen kunt werken aan één code;
  • je code met anderen kunt delen.

Git vs. GitHub

Git houdt de geschiedenis van je code bij. GitHub is een online platform waar je je Git-projecten kunt opslaan en delen.

13 · Basic Linux commands

Linux commands

We hebben ook een aantal basiscommando's voor Linux geleerd: ls, cd, mkdir en touch.

ls

Met ls zie je welke bestanden en mappen zich in de huidige map bevinden.

cd

Met cd kun je veranderen van map.

mkdir

Met mkdir maak je een nieuwe map aan.

mkdir python

Hiermee maak je een map met de naam python.

touch

Met touch kun je een nieuw leeg bestand maken.

touch rekenmachine.py

Hiermee maak je bijvoorbeeld een nieuw Python-bestand met de naam rekenmachine.py.

14 · Programmeren in bedrijven

Programmeren in bedrijven

De programmeeronderdelen kunnen ook in de echte wereld worden gebruikt.

Variables kunnen bijvoorbeeld worden gebruikt om gegevens van een gebruiker op te slaan. If en else kunnen worden gebruikt om beslissingen te maken, zoals controleren of iemand genoeg geld heeft om iets te kopen.

Loops kunnen ervoor zorgen dat een programma iets blijft herhalen, bijvoorbeeld in een game. Input en print worden gebruikt om te communiceren.

Random kan worden gebruikt voor willekeurige gebeurtenissen in games. Git en GitHub worden door programmeurs gebruikt om code te bewaren, versies bij te houden en samen aan projecten te werken.

De Linux-commando's kunnen worden gebruikt om bestanden en mappen vanaf de terminal te beheren.
